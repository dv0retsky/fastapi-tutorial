## 🚀 О проекте

Учебный материал включает **теоретические сведения и практический материал**, посвящённый созданию современных серверных приложений на **FastAPI**.

В курсе вы научитесь:
- проектировать REST API и работать с HTTP методами;
- валидировать входящие данные с помощью **Pydantic**;
- реализовывать **аутентификацию и авторизацию** (Basic Auth, JWT, RBAC);
- подключать базы данных и выполнять операции **CRUD**;
- управлять схемой базы данных через **Alembic**;
- обрабатывать ошибки и формировать единый формат ответов API;
- писать **юнит- и интеграционные тесты**;
- использовать **WebSocket**;
- развертывать приложения через **Docker** и ASGI серверы.

Курс предназначен для всех, от начинающих до тех, кто хочет системно углубить знания в backend-разработке и построении API.

---

## 🛠 Технологии и инструменты

- **Python 3.10+ / 3.11+**
- **FastAPI**
- **Uvicorn** (ASGI сервер)
- **Pydantic**
- **SQLAlchemy** (ORM)
- **Alembic** (миграции БД)
- **Pytest** (тестирование)
- **Docker** (развертывание)
